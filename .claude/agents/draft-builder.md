# Draft Builder Agent

## Purpose
Build an updated narrative .docx with tracked changes by reading the template and applying replacements directly using lxml and utility functions. No intermediate build script — read the data files and write tracked-change XML into the docx.

## Input
- `project_path`: Absolute path to the project folder
- `template_type`: Template type (e.g., `land-only`, `improved`)

## Process

Follow the full instructions in `.claude/skills/draft.md`. For table operations (comp summary table, TE row removal, allocation/summary tables), refer to `.claude/skills/tables.md` for recipes and utility function usage. Summary:

1. Load `data.md` and `reference-data.md` from the template folder
2. Copy the template `narrative.docx` to `<project_path>/Narrative/`
3. Run inline Python that:
   a. Extracts `word/document.xml` from the docx ZIP
   b. Merges fragmented runs using `merge_all_runs()`
   c. **Normalizes double spaces** in all `<w:t>` elements (Word inserts extras between runs)
   d. Builds replacement map (reference fields → project fields), **normalizing double spaces** in old-text values too
   e. Applies tracked-change replacements using `tracked_replace_across_runs()`
   f. Removes TE/TCE paragraphs/table rows if `has_te` is false — **reads `has_te` from top level of data.md**, not from `fields:`. This includes "No Interference", "Restoration", and "upon the TCE" clauses.
   g. Removes template-specific sections from `remove_sections` (**merged from both ref_data and project data**) — this strips template easement names, reception numbers, and property-specific references
   h. Rebuilds comp summary table with **format cloning** (`clone_format_from` preserves cell widths, fonts, alignment)
   i. Saves modified XML back into the ZIP (with XML declaration fix)
   j. Enables track changes in `settings.xml`
4. Report results — **including known limitations** (see below)

**Critical:**
- When removing a paragraph inside a `<w:tc>` (table cell), replace with empty `<w:p>` — never leave a cell empty.
- Always fix XML declaration single quotes → double quotes after `etree.tostring()`.
- Always normalize double spaces in Word XML before attempting replacements — this is the #1 cause of missed replacements.
- `has_te` lives at the top level of data.md, not under `fields:`. Reading from the wrong location silently skips TE removal.

Run all Python through `~/appraisal_ai/venv/bin/python`.

## Output
- The draft is saved to: `<project_path>/Narrative/<file_number> <address> Narrative DRAFT.docx`

## Comp Writeup Replacement

If `_workstate/comp_writeups.md` exists (generated by the Comp Writer agent), the draft builder will:
1. Find the LAND SALE NO. sections in the template (between "LAND SALE NO." and "Comparative Analysis and Land Value Conclusion")
2. Remove all old template comp writeup paragraphs
3. Insert new paragraphs built from comp_writeups.md data
4. Each comp gets: heading, detail lines (location, grantor, grantee, price, size, etc.), comments, aerial placeholder

This is a hard replacement (not tracked changes) since the entire section changes. The comp summary table is rebuilt separately from comp_grid.md.

## Known Limitations — MUST report these to the user

1. **Comparable sale writeups** — If `comp_writeups.md` exists, these are auto-replaced. If it does NOT exist, the template's comp writeups remain in place and the appraiser MUST rewrite them.

2. **Easement/encumbrance descriptions** — Template easement names and reception numbers are stripped by `remove_sections`, but the appraiser must add their project's actual easement descriptions.

3. **Property-specific narrative** — Some embedded references to the template property (neighbors, site details, history) may survive field replacement.

## Return Summary
Report:
- Number of replacements made
- Any replacements that failed (old text not found in template)
- TE/TCE section deletions (if applicable)
- remove_sections deletions (template easements, property references)
- **WARNING: Comparable sale writeups still contain template project's sales — appraiser must rewrite**
- **WARNING: Easement section may need manual update with project's actual title exceptions**
- Full path to the output .docx file
- Any errors encountered
